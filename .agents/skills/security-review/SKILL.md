# Security Review

`AGENTS.md`의 공통 보안 원칙을 따른다. 이 스킬은 보안 판단의 근거와 범위를 정한다.

## 절차

1. 분석 대상, 신뢰 경계, 보호할 자산, 공격자의 가능한 권한을 정한다. 대상 범위와 제외 범위를 기록한다.
2. 관련 입력점부터 민감한 동작까지 데이터 흐름과 방어 장치를 추적한다. 코드 위치와 설정 조건을 근거로 남긴다.
3. 취약점 후보마다 공격 전제, 실제 도달 가능성, 영향, 기존 완화책을 확인한다. 안전한 정적 분석이나 격리된 최소 재현으로 가설을 검증한다.
4. `확인됨`, `가능성 있음`, `근거 부족`, `오탐` 중 상태를 부여한다. 심각도는 영향과 악용 가능성을 설명한 뒤 정하고, 확신도를 별도로 기록한다.
5. 수정 방향과 재검증 방법을 제시한다. 변경이 요청 범위에 포함되지 않으면 코드 수정은 수행하지 않는다.

## 완료 기준

- 각 판정에 추적 가능한 위치·조건·관찰 결과가 있다.
- 미확인 가정, 재현 한계, 적용되지 않는 경우가 구분되어 있다.
- 위험도와 권장 조치가 제시된 근거를 넘어서 단정되지 않는다.
