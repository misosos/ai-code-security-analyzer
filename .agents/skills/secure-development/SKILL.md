# Secure Development

`AGENTS.md`의 공통 보안 원칙을 따른다. 이 스킬은 분석기 기능의 설계와 구현에 적용한다.

## 절차

1. 요구사항, 지원 입력, 결과 계약, 실패 시 동작을 확인하고 기존 모듈 경계를 살핀다.
2. 수집·파싱·정규화·탐지·판정·출력 중 해당 책임을 분리한다. 입력 데이터가 코드 실행, 네트워크 접근, 파일 쓰기를 유발할 수 있는 경로를 확인한다.
3. 탐지 규칙은 관찰 가능한 증거와 판정 조건을 분리해 구현한다. 불명확한 경우에는 확정 진단 대신 불확실성을 표현할 수 있게 한다.
4. 입력 오류, 큰 입력, 인코딩 차이, 경로 처리 등 해당 기능의 실질적 경계 조건을 다룬다. 기존 인터페이스와 오류 처리를 불필요하게 바꾸지 않는다.
5. 관련 검증을 실행하고 결과를 기록한다. 탐지 정확도나 회귀 검증이 핵심이면 `security-validation`을 함께 적용한다.

## 완료 기준

- 요구된 동작과 실패 경로가 구현되고 모듈 책임이 분명하다.
- 분석 대상의 비신뢰 입력이 의도하지 않은 실행·접근·기록을 유발하지 않는다.
- 변경에 맞는 검증 결과와 알려진 한계가 제시된다.
