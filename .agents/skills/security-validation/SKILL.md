# Security Validation

`AGENTS.md`의 공통 보안 원칙을 따른다. 이 스킬은 검증 사례와 관찰 결과를 다룬다.

## 절차

1. 검증할 동작과 판정 기준을 먼저 정한다. 지원 언어·규칙·입력 형식별로 영향 범위를 확인한다.
2. 취약 사례와 안전한 유사 사례를 쌍으로 준비한다. 실제 비밀정보와 외부 서비스 대신 합성 데이터와 격리된 픽스처를 사용한다.
3. 파서·규칙·결과 형식에 대한 단위 테스트와 이전 결함의 회귀 테스트를 우선 배치한다. 필요한 경우 입력 변형과 경계 조건을 추가한다.
4. 탐지 결과를 기대 라벨과 비교해 TP, FP, FN, TN을 구분한다. 수치 지표를 제시할 때는 데이터셋 범위와 표본 수를 함께 밝힌다.
5. 실행 명령, 환경, 결과를 기록한다. 실패 사례는 재현 입력과 기대·실제 결과로 축소하고, 수정 후 같은 검증을 다시 실행한다.

## 완료 기준

- 핵심 성공·실패 경로와 중요한 오탐·미탐 사례가 검증된다.
- 테스트가 독립적으로 재실행 가능하고 외부 상태에 의존하지 않는다.
- 통과·실패·미실행 항목과 정확도 주장의 적용 범위가 명확하다.
