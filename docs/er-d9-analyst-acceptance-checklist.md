# ER-D9 분석가 수동 수용 기록

상태는 `PASS`, `FAIL`, `NOT_TESTED` 중 하나를 사용한다. 기본값은 `NOT_TESTED`다. 재현 환경을 준비한 다음 실제 macOS Safari에서 사용자가 직접 수행한다. 실제 사용자 소스·Token·Handle·내부 절대 경로는 기록하지 않는다.

| ID | 확인할 질문 | 상태 | 관찰과 재현 단계 |
| --- | --- | --- | --- |
| A01 | Finding 미관찰이 해결 완료의 증거가 아니라는 설명을 이해했는가? | NOT_TESTED | |
| A02 | 특정 경로의 Skip 관찰과 전체 검사 완료를 구분했는가? | NOT_TESTED | |
| A03 | 선택 규칙 바이트와 전체 Loaded Rule Identity의 차이를 이해했는가? | NOT_TESTED | |
| A04 | Gap Map에서 미수집·미검증 영역을 찾을 수 있는가? | NOT_TESTED | |
| A05 | 표시된 근거에 맞는 후속 확인 작업을 선택할 수 있는가? | NOT_TESTED | |
| A06 | Partial/INCOMPARABLE을 정상 완료로 오해하지 않는가? | NOT_TESTED | |
| A07 | 조사 증거 해제 뒤 재조사가 차단되는가? | NOT_TESTED | |

검수일: NOT_RECORDED. 실제 실행 SHA: NOT_RECORDED. macOS 및 Safari 버전: NOT_RECORDED. 민감정보 제거 화면 캡처: NOT_PROVIDED. 실패 시 기대·실제 결과와 안전한 재현 단계를 기입한다. 자동화 Chromium/WebKit은 이 표의 PASS가 아니다.
