> 빈 템플릿입니다. 실제 참가자 응답이나 측정값이 포함되어 있지 않습니다. 참가자 기록을 이 파일에 저장하거나 Git에 커밋하지 마세요.

## 세션 메타데이터

- 자료 버전: `phase3c2-questionnaire-v1`
- 화면 기준 커밋: `c8fff609b8ab04093b193e6192bf58249cd3001e`
- 합성 화면 종류: `[taint / pattern / partial / failed / zero]`
- 익명 참가자 코드: `[예: P-01; 실제 계정·이름과 연결 금지]`
- 경험 범주(선택): `[보안 입문자 / 정적 분석 경험 개발자 / 보안 분석 경험자 / 미기록]`
- 응답 기록 상태: `[미작성 / 작성 완료 / 검토 후 비식별화]`

이름, 이메일, 연락처, 조직·팀, 계정 ID, 실제 업무 코드나 실제 보안 사건을 기록하지 않습니다.

## 관찰 메모

- 해석 오류 유형 및 문항 번호: `[없으면 없음; 응답을 그대로 복사하지 않음]`
- 이해하기 어려웠던 문구: `[화면 문구만 기록; 참가자 식별 단서 제외]`
- 참가자 제안: `[비식별 요약; 없으면 없음]`
- 진행자가 설명을 제공했는가: `[아니요 / 예 — 문항 번호와 설명 시점만 기록]`
- 민감정보 검토 완료: `[아니요 / 예]`

진행 중 정답을 안내하거나 유도하지 않습니다. 점수는 실제 답변을 받은 뒤에만 채웁니다. 이 양식은 형성 평가용이며 소표본 결과를 전체 사용자 집단에 일반화하지 않습니다.
