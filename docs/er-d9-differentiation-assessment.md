# ER-D9 기존 비교와 조사 증거의 차이

| 기준 | 기존 ScanResponse와 Comparator | ER 조사 및 Gap Map | 남은 한계 |
| --- | --- | --- | --- |
| Finding 변화 | ID·규칙·위치·심각도와 ID 범주를 제공 | 같은 응답에 연결된 서버 Evaluation의 범주를 재검증 | ID는 의미상 동일 취약점을 증명하지 않음 |
| 경로 제외 | 일반 Comparator는 부분 검사를 차단 | B 경로가 제외됐다는 제한된 절차 관찰과 후속 Ignore 확인을 제공 | 전체 검사 범위와 유일한 원인은 미확정 |
| 규칙 바이트 | 같은 프로필 ID를 표시 | 선택된 단일 파일 사본의 바이트 같음/다름을 별도 표시 | 로딩된 전체 규칙이나 의미상 동작은 미검증 |
| 소스 변경 | Finding 차이만으로 직접 확인 불가 | Snapshot 미수집과 별도 변경 기록 확인을 표시 | Git Diff를 자동 수집하거나 원인을 확정하지 않음 |
| 검사 범위 | 검사 상태 및 생략 여부를 확인 | Skip 관찰과 전체 범위 미검증을 표시 | 모든 규칙의 성공적 적용을 증명하지 않음 |
| 후속 작업 | 기존 비교도 후속 검토 안내 제공 | 해당 관찰과 연결된 경로·규칙·소스 확인 순서를 제시 | 작업 수행이나 사용자 이해를 확인하지 않음 |

이 비교는 이 제품의 기존 Comparator와 구현된 ER 계약을 대상으로 한다. 다른 도구 전체에 대한 우월성 비교가 아니다. 실제 분석가의 판단 정확도, 시간 절감과 효율 개선은 사람 대상 실험 없이 입증되지 않았다. 검사의 완료나 Finding 미관찰은 코드 안전성 또는 취약점 해결의 증거가 아니다.
